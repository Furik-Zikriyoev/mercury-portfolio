# mercury-portfolio

Моё портфолио. Frontend-разработчик и UI-дизайнер, Ташкент.

**Сайт:** https://mercury-portfolio-ten.vercel.app

Пока в разработке.

## Стек

- Vue 3, TypeScript, Vite
- WebGL2: эффект жидкого металла на своём шейдере, без three.js
- Локализация RU/EN на TypeScript, без библиотек
- ESLint, Prettier
- Vercel

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов и сборка
npm run preview    # просмотр сборки
```

Нужен Node.js 20.19+. Тестовая страница движка: `/?lab`.

## Структура

```
src/
├── engine/        # WebGL-движок жидкого металла, не зависит от Vue
├── components/    # MercuryCanvas, MercuryText, UI
├── composables/
├── content/       # тексты RU/EN и контакты
├── lab/           # тестовая страница движка
└── styles/        # дизайн-токены и базовые стили
```

## Как устроен металл

Один полноэкранный `<canvas>` поверх страницы (`pointer-events: none`), один фрагментный шейдер.

- **Капли** — метаболы с ядром `r² / (d² + r²/4)`.
- **Текст** — символы рисуются в offscreen canvas по координатам из DOM (`Range.getClientRects`), маска размывается и уходит в текстуру `R16F`. HTML-текст остаётся на странице, просто становится прозрачным.
- **Рамка** — SDF скруглённого прямоугольника, считается прямо в шейдере.
- Всё складывается в одно поле, поверхность там, где поле > 1, поэтому капли, буквы и рамка сливаются друг с другом.
- Нормаль берётся из градиента высоты `sqrt(1 − 1/f)`, цвет — отражение процедурного окружения.
- Физика капель — пружины к целевым точкам, гравитация и отскок от краёв в свободном режиме.
- Если FPS долго ниже 45, разрешение рендера снижается. Без WebGL2 текст показывается обычным HTML.
